# 安全与数据处理

## 安全边界

Agent-SkillOpt 默认只做本地文件系统检查和命令渲染。dry-run 不启动上游子进程，
不创建网络客户端，也不向模型提供商发送请求。

真实运行必须同时满足：配置声明了密钥环境变量名、该环境变量已设置、用户在命令中
显式确认 allow-network。该确认旨在阻止复制命令时意外产生计费或数据外发。

## 密钥规则

- 只在父进程环境中保留 API 密钥；配置只保存环境变量名称。
- 仅在启动上游子进程时把密钥传入子进程环境。
- 禁止在命令行、配置、manifest、报告、日志、测试 fixture、截图或 Git 历史中保存密钥值。
- doctor 只报告环境变量是 set 还是 missing，绝不回显其值。

如怀疑密钥已经泄露，请先在提供商侧撤销或轮换密钥，再从本地文件、提交和外部日志
中清除泄露内容。不要把真实密钥附在 issue、聊天记录或漏洞报告中。

## 数据外发

启用网络后，上游训练可能把 prompts、轨迹、数据样本或其派生内容发往配置的端点。
运行前必须确认数据授权、提供商处理规则、保留期限、区域与计费范围。敏感、受限或
未经授权的数据不得用于远程实验。

## 运行证据

manifest 仅记录端点主机名、模型标识、配置哈希、上游版本、路径、seed、调用参数和
状态。它不保存完整端点查询串、密钥或推断出的成本。

## 漏洞报告

在仓库公开后，请优先使用 GitHub 的私密安全公告或维护者约定的私密渠道。报告中请
提供可复现的最小案例，并用占位符替代所有凭据与私有数据。公开 issue 只应用于不会
暴露用户、密钥或可利用细节的问题。
